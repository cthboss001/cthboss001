**Shipped:**

| Project | Description |
|---|---|
| **[Thunder](https://www.thunderchat.tech)** | Invite-only messaging platform my friends and I use every day. NestJS REST and Socket.IO backend, Next.js web client and a native Kotlin Android client on one shared contract. Server-side sequence numbers with gap-fill on reconnect, WebRTC voice and video calls with a TURN fallback for carrier NAT, and voice notes transcoded with ffmpeg so they play on iOS. |
| **[Forum BD](https://forumbd.online)** | Community forum for Bangladesh, live with members. TanStack Start (SSR), React 19 and Supabase Postgres. Authorization is enforced by row-level security on every public table, and sign-in limits are keyed on a hash of IP and device fingerprint, so raw IPs never reach the database. |
| **[texAi](https://github.com/cthboss001/texai)** | Windows tray app that rewrites selected text in place with a local Ollama model: select text in any app, press Ctrl+Alt+G, and the selection is replaced. C#, .NET 8, WPF and Win32 hotkeys. The clipboard is restored after every rewrite and text never leaves the machine. v2.0.3 released. |
| **[IntCart](https://www.intcart.shop)** | The storefront and admin system behind my own e-commerce business. Next.js, TypeScript, PostgreSQL and Prisma. Checkout runs in one interactive transaction, optimistic locking stops two buyers taking the last item, and orders snapshot their line items so old invoices stay correct. TOTP 2FA for admin accounts. |
| **[RetinaRest](https://tazim.dev/retinarest)** | Windows desktop app that enforces the 20-20-20 eye-rest rule. The timer is a finite state machine persisted to SQLite, so a crash or reboot does not lose the session. Guest mode is fully local; Google sign-in adds sync through Supabase with RLS. **15 releases shipped** with silent background updates. |
| **[MovieVault](https://movies.tazim.dev)** | One archive for every film I have rated on IMDb and Letterboxd. Imports are merged with duplicate detection, filled in from TMDB, searchable with Fuse.js fuzzy matching, with a stats page for runtime, genres and yearly trends. |
